# 원페이지 스크롤 제어

2026-09-28 사용자 요청으로 초기 동작을 변경했습니다. 페이지가 보이고 조작이 없는 상태로 30초가 지나면 0.5배속으로 시작하며, 반복 버튼은 기본 켜짐입니다. 정적 GitHub Pages 배포는 유지합니다.

## AUTO / Off / 속도

- AUTO는 실제 버튼입니다. 클릭·탭·Enter·Space로 즉시 0.5배속을 시작합니다.
- 방문 시 이동은 정지 상태이며, AUTO의 보조 문구가 `30초 대기`를 표시합니다.
- 30초 동안 직접 조작이 없으면 0.5x(초당 24 CSS 픽셀)로 움직입니다. 1x는 48, 2x는 96 CSS 픽셀/초입니다. '0.5초마다 점프' 방식이 아닙니다.
- 포인터 이동, 휠, 터치, 키보드, 실제 페이지 이동·스크롤 등 직접 조작은 재생을 멈추고 마지막 조작부터 30초를 새로 셉니다.
- Off는 재생뿐 아니라 30초 자동 시작과 예약된 상단 복귀도 중단합니다. 반복 버튼의 선호 상태는 유지되지만 Off 중에는 반복 이동하지 않습니다. 같은 페이지에 머무는 동안 AUTO나 속도 버튼을 다시 누르기 전에는 켜지지 않습니다. 새로고침하면 기본 대기 정책을 다시 적용합니다.
- 속도 버튼은 현재 재생 속도를 나타냅니다. Off가 강조되고 AUTO에 '30초 대기'가 보이면 현재 이동은 없고 대기 예약만 켜진 상태입니다.

## 보호 조건

입력 요소에 포커스가 있거나 수동으로 문의 영역에 도착했거나 메뉴가 열려 있거나 포인터/터치를 누르고 있으면 무조작 시작을 하지 않습니다. 숨긴 탭이나 포커스를 벗어난 창에서는 타이머와 이동을 취소하고, 돌아오면 새로 30초를 기다립니다. 문의 구간에서는 취소된 반복 복귀를 되살리지 않습니다.

운영체제의 동작 줄이기 설정에서는 무조작 시작과 자동 반복을 하지 않습니다. 사용자가 명시적으로 AUTO/속도를 선택하는 것은 허용하지만 이후 다시 방치했을 때 자동 재시작하지 않습니다.

스크롤 프레임은 누적 소수점 위치를 사용하며 자체 scroll 이벤트로 중지되지 않도록 구분합니다. 수동으로 문의 영역에 진입한 경우에는 상단으로 복귀하거나 자동 재시작하지 않습니다. 자동 재생으로 종료 지점에 도착한 경우에만 아래 반복 정책을 적용합니다. 페이지를 벗어나면 타이머·프레임·이벤트를 정리합니다.

## 기본 켜짐 반복 버튼

- 매 방문/새로고침 시 `반복`은 켜짐(`aria-pressed=true`)입니다. 페이지는 기존처럼 30초 대기로 시작하며 즉시 움직이지 않습니다.
- AUTO/속도 버튼 또는 30초 무조작으로 시작한 재생이 종료 지점(문의 구간 시작 또는 문의 구간이 없는 페이지의 맨 아래)에 도달하면 5초간 정지합니다.
- AUTO 보조 문구에 `5초 후 처음`부터 초 단위 복귀 안내를 표시합니다. 사용자가 개입하지 않으면 긴 역방향 애니메이션 없이 맨 위로 복귀한 뒤 0.5배속으로 재생합니다.
- 반복을 끄면 진행 중인 재생 속도는 유지하고 종료 지점에서 멈춥니다. 대기 중에 끄면 예약된 복귀가 취소됩니다.
- 반복 선호를 켜는 것만으로 정지된 재생을 시작하거나 Off를 해제하지 않습니다. 저장소 접근 없이 메모리 내 상태만 사용합니다.
- 직접 조작, 문의 입력/입력 포커스, 메뉴 열기, 포인터/터치 누름, 탭 숨김/창 이탈, 동작 줄이기 설정은 예약된 복귀를 취소합니다. 탭으로 돌아왔다고 취소된 복귀를 되살리지 않습니다.
- 페이지를 벗어나거나 컴포넌트를 해제하면 반복 타이머와 프레임, 이벤트를 모두 정리합니다.
- 프로그램이 발생시킨 마지막 scroll 이벤트와 상단 복귀 이벤트가 사용자 입력으로 오인되어 반복을 취소하지 않도록 구분합니다.
- 상단 복귀 시 주소에 해시가 있으면 기존 history 상태를 보존하고 현재 항목만 #start로 교체합니다. 반복할 때마다 뒤로가기 기록을 추가하지 않습니다.

## 서비스 세부 목차

- 서비스 구간 진입: 왼쪽 목차 아래에 정사영상 / 데이터 구축 / 컨설팅 / 소프트웨어 / 교육을 표시합니다.
- 각 세부 항목 클릭: 같은 페이지의 #ortho / #data / #consult / #software / #edu로 이동합니다.
- 직접 스크롤 또는 자동 스크롤: 현재 항목과 SVG 연결선이 해당 서비스 제목을 따라갑니다.
- 서비스 구간 이탈: 하위 목차를 접고 다음 상위 구간을 표시합니다.
- 작은 화면: 서비스를 읽을 때만 가로 빠른 이동 메뉴가 나타납니다. 전체 모바일 메뉴에도 같은 하위 목차를 제공합니다. 전체 메뉴를 강제로 열지는 않습니다.
- 짧은 화면: 세부 목차는 메뉴 내부에서 스크롤할 수 있으며 본문을 강제로 움직이지 않습니다.

## 검증

`tests/story-idle-navigation.spec.ts`에서 Playwright Clock으로 실제 운영 상수 30,000ms를 변경하지 않고 경계 시간을 검증합니다. AUTO 클릭/탭/키보드, Off 취소, 입력·가림·누른 포인터 보호, 서비스 자동 펼침/접힘, 현재 항목, 직접 해시 접근, 320px 모바일과 짧은 데스크톱 화면을 검사합니다. 기존 서비스·문의 회귀 검사도 유지합니다.

`tests/story-repeat.spec.ts`는 반복 기본 켜짐, 복귀 대기와 0.5배속 재개, 반복 끄기, Off, 사용자 조작, 숨김 탭, 문의 작성, 수동 문의 진입, 동작 줄이기, 320~1440px 컨트롤 배치를 검사합니다.

외부 지도와 문의 서비스는 테스트에서 모의 처리합니다. 운영 문의를 실제 전송하는 테스트가 아닙니다. 기존 배포 워크플로는 검증 후 운영 Secrets로 다시 빌드하며 테스트용 키 산출물을 배포하지 않습니다.
